# Architecture audit against the current course contract

**Target:** architecture revised 2026-10-16 under the [accepted mandate](../deep_networks_revision/instructor_mandate.md). This audit evaluates implementation and does not independently define the course philosophy. Prior audit versions and exact reviews remain in Git; they are not silently reassigned to the new sequence. The planned map owns detailed topic/source allocations.

The new course endpoint combines probabilistic task/query formulation, structure-sensitive computation, problem-specific method choice and a practical repertoire. The neural revision strengthens learned representation and architecture competence at an explicit cost: general MH/Gibbs/HMC/AIS algorithm understanding is no longer promised. Prior PyMC use supports a supplied-sampler encounter but cannot justify claims of transition-design or convergence-theory competence.

The retained sampling argument in L07 is mathematically bounded. For iid target draws with finite variance, a sample average has variance Var(g)/N. Dependent output needs long-run variance/MCSE assumptions; diagnostics can expose failure without proving adequate exploration. L07 must replace grid/coordinate details to fund this encounter. L09 samples from q to optimize an expectation; these are not automatically target-posterior draws. L11/L12 generative draws have different roles again. No hidden replacement MCMC lecture is funded elsewhere.

L10 and L11 have different reusable arguments: learned local composition and parameter sharing on images, then context compression/retrieval on sequences. A network output parameterizes a probability law; its hidden functions need not be random variables. RNN state is deterministic given a prefix, unlike an HMM hidden state that is marginalized. Causal attention must exclude unavailable observations, and attention needs an account of order. Dense attention's quadratic context storage and recurrent sequential dependence are regime-specific tradeoffs, not blanket architecture rankings. The two hour-long notebooks must remain narrow enough for scaffolded mathematical, software and interpretive work.

L12 reuses ELBO, pathwise gradients and neural roles. Its Gaussian reconstruction density is applied from L01 with explicit event sums; the previous full heteroskedastic-head derivation is no longer a prerequisite. Preserve the correct decomposition E_x KL(q(z|x)||p(z)) = I_q(X;Z) + KL(q(z)||p(z)), rather than equate rate with mutual information. City preprocessing, zero handling and inverse-transform density/observation meanings remain real validation duties.

The strongest existing early material is retained for reciprocal reconciliation. L01 Gaussian conditioning needs its accepted live residual proof and protected timing, plus the required/examinable separate block-elimination content. L02's accepted Markov modeling cycle makes the later sequence return meaningful. L03 graph representation and independence must not be displaced by a convenient image solver; ICM remains local optimization, not global MAP or posterior sampling.

Remaining limits are concrete: full detailed scope acceptance, measured live pacing, actual one-hour learner workload, portable data/checkpoints, and clean hosted Colab execution. A source notebook or quick numerical probe answers none of these by itself. The new independent preview and source/probe records belong in [deep networks revision](../deep_networks_revision/); exact earlier source reviews remain identifiable in [review index](source_arc_review_index.md).
