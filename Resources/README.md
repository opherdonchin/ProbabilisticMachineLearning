# Online reference PDFs

The PDFs kept in this directory are local reference copies and are not committed
to the repository. Use the authors' official downloads for the two course books:

| Book | Official page | PDF |
| --- | --- | --- |
| Kevin P. Murphy, *Probabilistic Machine Learning: An Introduction* (Book 1) | [Book 1 page](https://probml.github.io/book1) | [Download PDF](https://github.com/probml/pml-book/releases/latest/download/book1.pdf) |
| Kevin P. Murphy, *Probabilistic Machine Learning: Advanced Topics* (Book 2) | [Book 2 page](https://probml.github.io/book2) | [Download PDF](https://github.com/probml/pml2-book/releases/latest/download/book2.pdf) |

The download links point to the latest author-hosted drafts. They may differ from
local copies such as `book1.pdf` and `book2-1.pdf`. The reading packets, the
Bayesian-statistics PDF, and the lecture-split PDFs under `Old/` are local files;
this index does not claim that they have identical standalone online editions.
