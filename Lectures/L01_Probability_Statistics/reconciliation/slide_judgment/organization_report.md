## Minimal proposed instruction changes (unaccepted)

For Organization, add one sentence to the existing handoff quality test:
“Name the relation that connects the slide's necessary mathematical objects
(e.g. construction, substitution, derivation or optimization), and check that
its intended reading survives in one complete normal-scale realization.”
This supplements the title-sequence test; it does not transfer finished layout,
wording or reveals to Organization. A complete teaching-move sequence can pass
that test while its realized slide body obscures the reasoning.

For the shared exchange, add a short requirement to a prototype offer:
“State which relational uncertainty the contrast tests, hold mathematical
selection fixed when isolating composition, and say what observed result would
count against each option.” The existing convergence contract already requires
actual alternatives, preserved content and inspected states; a new style
catalogue or extra approval stage is unnecessary.

Design/Authoring should decide their own wording for corresponding deltas. The
candidate lesson is that the hierarchy should expose mathematical roles and
operations; it is not “make labels bigger,” “add borders,” “use three columns,”
or “add whitespace.” The transfer test must distinguish a useful relation from
a copied visual template before any general rule is proposed for adoption.
